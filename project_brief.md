# My agent: Authentic Adventure Travel Concierge

One-liner: A conversational agent that helps budget-conscious adventurers discover local culture and authentic human interactions through tailored itineraries and walking tours capped at 4 hours.

Tool coverage:
- Memory: User travel preferences (value-for-money focus, preference for local culture & meeting people, max 4-hour walking tour constraint, dietary/budget limits, past saved trips).
- Tools: Walking tour route lookup (filtered to max 4h), local community event search, activity recommendations, and itinerary generator tool.
- Catalog/UI: Collections of walking tour stops, local meetups, and daily itineraries rendered as A2UI cards and structured tables.
- Image gen: Visual postcards and scenic neighborhood previews for suggested local spots.
- Sandbox: Walking tour duration/distance calculator and budget balancing calculator.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for route duration & budget math, Google Maps API integration, Cloud Trace for observability
